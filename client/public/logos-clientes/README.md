# Logos de clientes

Coloque aqui os arquivos de logo autorizados pelos clientes e referencie-os no
campo `logo` de `client/src/components/shared/Testimonials.tsx`.

Esperado:
- legalbot.png (ou .svg)
- small-nanotechnology.png (ou .svg)

Preferência por SVG ou PNG com fundo transparente. Como o site é escuro, logos
com texto escuro precisam da versão clara ou monocromática.
